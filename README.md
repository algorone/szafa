# Wstęp

### [Wirtualna szafa EZD  z dokumentacją elektroniczną](https://www.algor.com.pl/ezd).

Szafa zapewnia dostęp do metadanych i metryk spraw oraz metadanych akt, obsługe indeksów w sposób pozwalający dotrzeć do pozycji akt w repozytorium dokumentów elektronicznych. 
Repozytorium, zbudowane jako monorepo.


## Komponenty

| Nazwa | Opis|
| :-: | :-: |
| szafa-ezd | Zapewnia dostęp do metadanych i metryk spraw oraz metadanych akt pozwalający dotrzeć do pozycji akt w rejestrze dokumentów elektronicznych. |
| repozytorium-ezd |  Skład dokumentów elektronicznych stanowiących akta spraw, pozwala odnaleźć dokument po jego identyfikatorze.  |
| index-ezd |  Zapewnia dostęp do lokalizacji metadanych w postaci przeszukiwanego indeksu po kluczach i hasłach. |
